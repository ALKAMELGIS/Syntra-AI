# Earth textures

- `earth-day.jpg`: NASA Blue Marble, public domain (NASA Visible Earth).
- `earth-night.jpg`: NASA Earth at Night / Black Marble, public domain.

Both were taken from the `three-globe` npm package (MIT, v2.45.6,
`example/img/earth-blue-marble.jpg` and `earth-night.jpg`) and resized to
1024 x 512 for the sign-in globe (`components/EarthGlobe.jsx`).
